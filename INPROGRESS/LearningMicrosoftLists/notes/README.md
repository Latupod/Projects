# Personal Notes

Use this folder for your own learning artifacts:

- `exercise-01.md`, `exercise-03.md`, etc. — reflections from the learning path
- `capstone-brief.md` / `capstone-design.md` — your capstone project docs
- Screenshots (`.png`) of views, rules, or flows you build
- `gotchas.md` — things that confused you and how you solved them

There is no required format. Write what helps you remember.
