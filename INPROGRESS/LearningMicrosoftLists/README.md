## Quick start (5 minutes)

1. Read [What is Microsoft Lists?](docs/01-what-is-microsoft-lists.md)
2. Open Lists: [https://lists.microsoft.com](https://lists.microsoft.com) (requires Microsoft 365 work/school account)
3. Create your first list using the **Issue tracker** template
4. Follow [Exercise 1](docs/03-hands-on-learning-path.md#exercise-1-issue-tracker-your-first-list) in the learning path

## Prerequisites

- A **Microsoft 365** subscription (Business, Enterprise, or Education) with Lists enabled, **or**
- Access through **Microsoft Teams** (Lists app in the left rail or as a channel tab)
- Optional later: **Power Automate** and **Power Apps** for automation and custom forms

## Suggested learning order

```
Week 1: Concepts + first list (docs 01–02, Exercise 1)
Week 2: Views, columns, rules (Exercise 2–3)
Week 3: Teams integration + sharing (Exercise 4)
Week 4: Power Automate basics (Exercise 5)
Ongoing: Build a list for a real problem you have (notes/)
```
