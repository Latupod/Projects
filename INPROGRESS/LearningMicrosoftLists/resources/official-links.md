## Templates to try first

Built into the **+ New list** dialog:

1. **Issue tracker** — general workflow practice
2. **Asset manager** — person + date + status patterns
3. **Event itinerary** — calendar view practice
4. **Recruitment tracker** — multi-column design reference
5. **Content scheduler** — calendar + person fields
